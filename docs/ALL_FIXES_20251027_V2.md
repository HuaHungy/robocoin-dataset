## 🎯 诊断指南

### 如果看到"处理了太多episodes"

检查：
1. **Server启动命令**
   ```bash
   ps aux | grep server.py
   ```
   - 有 `--is-test` → Test模式（应该只处理2个episodes）
   - 没有 `--is-test` → Formal模式（会处理所有episodes）

2. **Client日志开头**
   ```
   🚀 Starting conversion in TEST MODE  → Test模式
   🚀 Starting conversion in FORMAL MODE → Formal模式
   ```

3. **Converter日志**
   ```
   🧪 Test mode: processing only 2 tasks  → 生效
   📊 FORMAL mode: processing all episodes → 正常
   ```

### 如果任务失败后卡在PROCESSING

检查：
1. **数据库schema**
   ```bash
   sqlite3 db/datasets.db ".schema lerobot_format_convert_test"
   ```
   应该有：total_episodes, converted_episodes, skipped_episodes

2. **Server错误日志**
   ```bash
   grep -i "error\|exception" server.log | tail -50
   ```
