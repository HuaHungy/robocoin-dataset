### ✅ 0. 测试模式严格检查修复 - leju字段缺失问题

**问题**: leju测试时遇到字段缺失（配置期望`state/*`，数据只有`action/*`），抛出`ConfigError`，测试无法完成

**根本原因**:
- 测试模式仍然使用严格模式（`is_strict = global_ep_idx < self.strict_episodes`）
- 前N个episode检测到字段缺失 → 抛出ConfigError
- 用户期望：测试模式应该跳过缺失字段的episode

**修复**:
```python
# Before
is_strict = global_ep_idx < self.strict_episodes

# After  
# 🧪 测试模式不使用严格模式（允许跳过字段缺失的episode）
is_strict = global_ep_idx < self.strict_episodes and not is_test
```

**效果**:
- ✅ 测试模式：遇到字段缺失 → 跳过episode + warning → 继续测试 → 完成
- ✅ 正式模式：前3个episode → 严格检查（检测配置错误）
- ✅ 正式模式：后续episode → 容错模式（跳过数据问题）

**影响数据集**:
- leju (乐聚) - 当前报错数据集
- 所有可能存在字段缺失的数据集

**详细文档**: `docs/TEST_MODE_STRICT_FIX.md`

### ✅ 1. FileExistsError修复 - 支持转换重试

**问题**: mmk2等数据集转换失败后，重试时报`FileExistsError`，无法自动恢复

**根本原因**: 
- lerobot库的`LeRobotDataset.create()`**不支持**`exist_ok`参数
- 内部硬编码使用`mkdir(exist_ok=False)`
- 之前失败的转换留下目录残留

**修复**:
- 在创建前检查并删除已存在的目录
- 添加重试机制（最多3次），处理并发竞态条件
- 详细的日志输出，便于诊断

```python
def _create_lerobot_dataset(self) -> LeRobotDataset:
    # 检查目录是否存在
    if output_path.exists():
        # 删除旧目录（失败转换的残留）
        shutil.rmtree(output_path)
    
    # 尝试创建数据集
    try:
        return LeRobotDataset.create(...)
    except FileExistsError:
        # 重试机制（并发冲突）
        time.sleep(2)
        continue
```

**影响范围**: 
- ✅ 所有使用`LeRobotDataset.create()`的转换器
- ✅ mmk2, galaxea, yinhe, leju, alohanew等
- ✅ 支持失败任务自动重试

**详细文档**: `docs/FILE_EXISTS_ERROR_FIX.md`

### ✅ 4. galaxea视频解码问题 - 初始化采样优化

**问题**: 
```
RuntimeError: Failed to read frame 0 from .../3115_cam_high.mp4
- 视频文件存在 ✓
- OpenCV无法解码 ❌
```

**根本原因**: 
- galaxea视频使用不兼容的编码格式（可能是AV1/HEVC）
- 初始化时使用 `LazyVideoReader` (OpenCV cv2.VideoCapture)
- OpenCV编解码器支持有限

**修复策略**: 
分阶段使用不同的视频读取方式

| 阶段 | 方式 | 工具 | 原因 |
|------|------|------|------|
| 初始化采样 | 只读1帧 | PyAV | 更好的编解码器支持 |
| 测试转换 | 读11帧 | PyAV | 快速验证 |
| 正式转换 | 延迟加载 | OpenCV | 高性能，低内存 |

**代码修改**:

1. `lerobot_format_converter_h5_mp4.py` - 添加 `sample_only` 参数
```python
def _prepare_episode_images_buffer(
    self, task_path: Path, ep_idx: int, 
    is_test: bool = False,
    sample_only: bool = False  # 🆕 初始化采样模式
):
    if sample_only:
        # 🎯 只加载1帧，使用PyAV（更兼容）
        return self._load_frames_to_memory(ep_dir, max_frames=1)
    
    if is_test or self._is_test_mode:
        # 🧪 加载11帧，使用PyAV
        return self._load_frames_to_memory(ep_dir, max_frames=11)
    
    # 🚀 延迟加载，使用LazyVideoReader (OpenCV)
    return self._create_lazy_readers(ep_dir)
```

2. `lerobot_format_converter.py` - 智能检测并使用sample_only
```python
def _get_one_frame_image(self, args_dict: dict) -> np.ndarray:
    # 🔍 检查子类是否支持sample_only
    import inspect
    supports_sample_only = 'sample_only' in inspect.signature(self._get_frame_image).parameters
    
    for task_path, ep_idx in ...:
        if supports_sample_only:
            # 🎯 初始化采样模式（PyAV）
            image = self._get_frame_image(..., sample_only=True)
        else:
            image = self._get_frame_image(...)
```

**技术优势**:
- ✅ 更广的编解码器支持（H.264, HEVC, AV1, VP9等）
- ✅ 向后兼容（子类可选实现）
- ✅ 性能优化（正式转换仍用LazyVideoReader）

**受益数据集**:
- galaxea (星图/星海图)
- alohanew
- 所有H5+MP4格式数据集
